# Novità

Ogni versione ha qui la sua sezione: il testo diventa la nota della release su GitHub
e compare in Lieve quando propone l'aggiornamento.

## v0.1.0

Prima versione pubblica.

- Editor KTextEditor (lo stesso di Kate) con il tema "VSCodium Dark", `.editorconfig` e le scorciatoie
  principali di VS Code.
- Esplora risorse con le icone di VS Code (lette dalle estensioni già installate), ricerca nei file con
  ripgrep, apertura rapida `Ctrl+P`.
- Terminale Konsole integrato con gli stessi colori dell'editor.
- Più progetti: scelta del progetto all'avvio, una finestra per progetto in un solo processo,
  `Ctrl+R` per cambiare progetto, progetti recenti nel menu della barra delle applicazioni.
- Prettier al salvataggio con le regole di VS Code (`editor.formatOnSave`, `.prettierrc`, plugin).
- Pannello Git: preparazione, commit, sincronizzazione, differenze colorate, blame in linea e nella
  barra di stato.
- Aspetto in stile VS Code: riquadri arrotondati, schede a pillola scorrevoli, barra del titolo con
  ricerca, barra di stato, accento bordeaux.
- Aggiornamenti dall'app: Lieve avvisa quando esce una versione nuova e la installa con un clic.
